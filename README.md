# CraftLink

スマホのブラウザからMinecraftを操作するMOD。**Minecraft Java 1.20.1 / Forge 47.4.10（47系） / Java 17** 対応。

## 自分のPCで好きなMODと遊ぶ

配布ZIP `craftlink-host-forge-1.20.1-0.1.0.zip` 内のCraftLink JARを、自分のMinecraft 1.20.1 / Forge環境の `mods` へ入れます。遊びたいMODと依存MODも同じ環境に追加して、ワールド内で **F8 → みんなで参加 → 受付を開始**。スマホはQRを読み、PCで承認すれば参加できます。

ソースコードや開発用の起動スクリプトは不要です。各自のPCで別々の部屋を作れます。対応範囲・導入場所・接続手順は[PC向け導入手順](docs/HOST_SETUP.md)を参照してください。

## 起動時のログイン状態を選ぶ

VS Codeの **⌘ShiftB** で選択、または **`sh menu.sh` → 11** で切り替えます。

通常起動・学校用起動それぞれで選択を保存します。次回は指定なし、または **前回の状態を使う** で復元します。Microsoft認証情報も既存のDevAuth保存領域を再利用します（期限切れ・失効時は再認証が必要）。

| 指定 | 状態 |
| --- | --- |
| `sh run.sh --dev` | 開発用ゲスト（認証なし） |
| `sh run.sh --login` | Microsoftで認証したアカウント |
| `sh run.sh --cached-login --offline` | 保存済みの名前・UUID。ローカル用、再認証なし |

`sh school.sh` にも同じ指定を付けられます。中継の主催者認証は別途必要です。

## 開発シェルから自分のアカウントで起動

通常の `sh run.sh` は[DevAuth](https://github.com/DJtheRedstoner/DevAuth)を使うMicrosoft認証を有効にします。初回は `sh run.sh --prepare` で依存を取得し、`sh run.sh` を実行してコンソールに表示された認証リンクをブラウザで開いてください。Minecraft Java版を所有するアカウントで認証すると、次回から保存済みの認証で起動します。表示名だけの変更ではありません。

オンライン認証後にタイトル画面まで起動すると、名前・UUIDだけを `.craftlink/identity.json` に保存します（トークンは含みません）。学校のように認証APIへ接続できない場所では `sh run.sh --cached-login --offline` で同じ名前・UUIDのローカルプレイができます。これはMicrosoftで再認証したセッションではなく、オンライン認証が必要なサーバーには参加できません。保存前ならゲストへ切り替えず、自宅での準備手順を表示して停止します。`--prepare` だけでは本人情報を保存しません。

`sh run.sh --no-login` は従来の開発用ゲスト起動です。`--offline` はGradleの依存取得を抑える指定で、Microsoft認証の通信を無効にするものではありません。認証に失敗したときにゲストへ自動で切り替えません。

認証データは `.craftlink/dev-auth/` にローカル保存し、Git・配布ZIPには含めません。共有しないでください。認証ツールは開発起動のruntimeOnly依存で、利用者向けJARに同梱しません。

## 配布版の接続範囲

配布ZIPのJARはLAN・USB専用です。外部中継UI・外部URLを無効にし、公開IPからの直接アクセスは拒否します。利用者自身が別途プロキシやVPNを設定することまで禁止する仕組みではありません。

以下の中継付き起動は開発者向けの別プロファイルです。`sh school.sh` は外部中継を明示的に有効にして開発起動します。このプロファイルのJARでは利用者向けの `hostDistribution` を生成できません。

## 起動（Mac）

```sh
sh run.sh --login     # 自宅で一度タイトル画面まで起動し、本人情報を保存
sh school.sh          # 学校：保存済みの本人情報でオフライン起動・中継付きBOT参加
sh school.sh --online --login # 自宅：依存を取得し、オンライン認証して中継付き起動
sh run.sh --offline   # LANで起動（依存取得済み）
sh menu.sh            # 対話式メニュー（起動・ビルド・ログイン・追加MOD）
```

- VS Code：**⌘ShiftB**。Finder：**学校で起動.command**。
- 中継の初回設定にはRenderの認証キーが必要。
- ワールドを開き、表示されたQRをスマホで読むとBOTで参加。
- 通常起動は **F8 → 接続を開始**。**F9** でBOT全員停止。
- 名前・スキン・操作設定：スマホの **☰ → 設定**。

## ビルド

Java 17・Node.js 22・npmが必要です。

```sh
sh build.sh          # 初回・通常ビルド
sh build.sh offline  # 依存取得済みならオフライン可
```

配布用JAR：`build/libs/craftlink-forge-1.20.1-0.1.0.jar`。Forgeの `mods` に配置します。

導入手順付きの配布ZIP：`build/distributions/craftlink-host-forge-1.20.1-0.1.0.zip`。通常ビルドで両方を生成します。

## 接続方法

| 方法 | 条件 |
| --- | --- |
| LAN / Wi-Fi | PCとスマホが直接通信できるネットワーク |
| Android USB | `sh run-usb.sh`。adb・USBデバッグ許可が必要 |
| 別Wi-Fi / モバイル通信 | `sh school.sh`。HTTPS中継と双方のネット接続が必要 |

学校などの通信制限によっては中継に接続できません。QR・認証キーは公開しないでください。

## 制限

- 複数BOTはシングルプレイ／LAN公開のホスト用。通常サーバーでは自分のプレイヤーを操作。
- BOT映像は参加者全体で最大20回/秒の描画。人数・PC・回線で画質と遅延が変わります。
- Fabulous・シェーダーMODは未対応／未検証。iPhoneはAndroid USBモード非対応。
- Macの起動スプラッシュ対策は自動適用。

### BOTのModアイテム・装備

クリエイティブ一覧には、導入済みModのクリエイティブタブ、表示名、アイテムのNBT付きバリエーションをそのまま使用します。参加者をクリエイティブに切り替えると利用できます。

持ち物でアイテムを選び、装備先（頭・胴・脚・足・オフハンド）を選んで「装備する / 外す」を押してください。装備済みの枠を選ぶと、選択中のホットバーが空の場合に外せます。防具はBOTにも描画されます。使用操作はメインハンドから順にオフハンドへ試行します。

Curiosが導入されている場合は、Modパックのプレイヤー用スロットからBOT用のアクセサリー枠を作成して表示します。装着可否と取り外し可否はCurios側の判定に従います。Curios以外の独自アクセサリーAPI、プレイヤー専用の効果・GUI、独自の長時間使用処理が必要なアイテムは個別の互換対応が必要です。Curiosを入れた実ゲーム環境での効果・外観の確認は未実施です。

### コマンドでBOTのゲームモードを変更

PCのチャットから、参加者ルームを開いた状態で実行できます。参加者番号の候補はTabで補完できます。

- `/craftlink gamemode creative`：全員をクリエイティブに変更
- `/craftlink gamemode survival`：全員をサバイバルに変更
- `/craftlink gamemode creative 1`：1号だけをクリエイティブに変更
- `/craftlink gamemode survival 1`：1号だけをサバイバルに変更

末尾の `all` でも全員を指定できます。全員への変更やPCの参加者モードボタンは個別指定をリセットし、新規参加者にもそのモードを適用します。切り替え時には対象の操作入力と飛行を解除し、スマホへ表示を通知します。このコマンドはPC側のCraftLink管理操作で、チートの有効化は不要です。

### 携帯向けのゲーム操作

スマホの「設定 → タッチ」から、ジョイスティック＋タップ・十字キー＋タップ・ジョイスティック＋照準のプリセットを選べます。プリセットは操作ボタンの個別配置を初期化します。

- ジョイスティックは倒す量で移動速度を調整。十字キーには前方の斜め移動があり、押したまま指を隣の方向へ滑らせられます。
- 移動・視点スワイプ・ジャンプを別の指で同時操作できます。
- タップ操作ではブロックをタップして設置・使用し、敵をタップすると攻撃します。長押しで破壊し、指を動かすと破壊を解除して視点操作へ切り替えます。弓など使用時間のある手持ちアイテムは長押しで使用し、離すと使用を終了します。
- 照準操作では中央の照準に向けて攻撃・使用ボタンを使います。
- スニークとダッシュは切り替え式。クリエイティブではジャンプ2回で飛行を切り替え、飛行中はジャンプで上昇・スニークで下降します。
- インベントリはアイテム→移動先のタップで操作し、長押しで個数を調整、2回タップで半分を選択します。

操作はJava版BOTへの入力です。Bedrock版固有のゲームルールや、Modが独自に開く画面まで同一になるものではありません。ブラウザーのタッチ入力は自動検証済みで、弓などの長押し使用を含む実ゲームでの確認は未実施です。

### BOTのステータスと呼び寄せ

初期名は `Bot1`〜`Bot8` です。名前を設定するとその名前を表示します。PCのチャットから `/craftlink tp 1` で1号をプレイヤーの近くの安全な足場へ呼び寄せられます。番号はTabで補完できます。バニラのセレクターを使う場合は `/tp @e[type=craftlink:classroom_bot,tag=craftlink_bot_1,limit=1] @s` のように指定します（バニラのTPには通常のコマンド権限が必要です）。

装備枠と持ち物枠は同じサイズで、インベントリの3Dプレビューに防具と両手のアイテムを反映します。サバイバルでは体力・満腹度・経験値と防御力をHUDに表示し、クリエイティブでは隠します。ステータス効果の名前・強さ・残り時間は両モードで表示します。

BOTごとに満腹度と経験値を管理し、食事・消耗・自然回復・経験値オーブ取得を反映します。検証用の隔離したワールドで、装備プレビュー・体力・満腹度の消耗・経験値取得・効果・モード切り替え・指定BOTの呼び寄せを確認しました。

### Curios・武器Modと一緒にビルド・起動

```sh
sh build-mods.sh --offline
sh run.sh --mods --offline
# 学校用中継で起動する場合
sh school.sh --mods
```

`~/The-four-primitives-and-Weapons` をソースから再ビルドし、Curios 5.14.1（Minecraft 1.20.1用）とCraftLinkを `build/modpack/mods/` に出力します。このフォルダーの3つのJARをForge 1.20.1の `mods` に入れることもできます。外部ModはCraftLinkのJARに埋め込まず、別々のModとして読み込みます。開発起動ではForgeGradleで名前を変換したJARを使います。

別の場所なら `sh build-mods.sh --project "/path/to/The-four-primitives-and-Weapons"` を指定します。初回で依存キャッシュがない場合は `--offline` を外してください。武器Modは非対話で `7-test` としてビルドし、ソースは変更しません。武器Modを編集したら同じビルドコマンドを再実行してください。通常の `sh run.sh` はCraftLink単体で起動します。

`sh run.sh --mods` と `sh school.sh --mods` は起動のたびに自作武器MODをビルドし直し、ローカルのMODセットを更新してから最新版を読み込みます。Gradleの差分ビルドを使うため、変更がなければ再利用します。ビルドに失敗した場合は古いJARで起動せず停止します。`--offline` は自作MODのビルドにも引き継ぎます。別のソースを使うときは `CRAFTLINK_WEAPONS_PROJECT=/path/to/project sh run.sh --mods` を指定してください。

Curiosのプレイヤー用スロットをBOTのアクセサリー枠に反映します。アクセサリーの効果は各Modの実装に従い、Player専用の処理はBOTでは動作しない場合があります。

指定プロジェクト＋Curiosを読み込んだ隔離ワールドで、BOTの10個のアクセサリースロットと、武器Modのアイテム（darkness_book）の装着・取り外しを確認済みです。

### BOTのタッチ操作・コンテナ

- 装備を2列で並べ、枠の間を1pxに縮めました。画面の高さとアクセサリー数に合わせて正方形の枠を縮め、通常の持ち物画面をスクロールなしで表示します。「詳細操作」を開いた場合や極端に多数のアクセサリーがある場合は追加操作のためにスクロールします。
- アイテムはタップ→移動先で移動・同種をまとめます。持ち物を長押しすると緑のゲージと選択個数が増え、離した時の個数を移動できます。同じ枠の素早い2回タップは半分を選択します。選択後にキャラクター背景をタップするとその個数を捨てます。ホットバーの長押しは従来通り破棄です。
- ジョイスティックを前に大きく倒すとダッシュ。前進2回・単独のダッシュボタンも使えます。しゃがみ中は足場の端から落ちにくくなり、水中・飛行中の下降はボタンを押している間だけ行います。
- チェスト・作業台などを使うと、BOT専用のコンテナ画面を開きます。タップで持ち上げ・置く、約0.9秒の長押しで反対側へ高速移動。持ち上げた素材の上をなぞると、通過した枠へ1個ずつ置きます。コンテナ内の2回タップは同種を集めます。
- インベントリの「詳細操作 → クラフト」で2×2クラフト、作業台では3×3クラフトができます。レシピ本は現在作れるレシピを表示し、タップで素材を配置します。結果枠をタップして取得します。
- 上部のチャットボタンからメッセージとコマンドを送れます。コマンドは参加BOT自身の権限で実行します。主催者のOP権限は引き継ぎません。

標準のスロットを持つModのコンテナも表示できます。Mod独自の3D画面・追加ボタン・独自通信の完全な再現には個別対応が必要です。移動・使用・飛行の基本操作は [Minecraft Education公式のタッチ操作表](https://edusupport.minecraft.net/hc/en-us/articles/360055370012-Touch-Controls-for-Minecraft-Education) も参考にしています。

計都星の刀の光沢描画に必要なMod用の描画バッファーを、BOTの手持ちとアイコンにも使用します。他のModの手持ち描画で例外が発生した場合は、その描画を省略して世界の映像を継続します。世界の描画エラーも部屋の終了まで停止せず再試行します。

プレイヤー本人のCurios画面は、PCのインベントリ右側の「アクセサリー」ボタンから開けます。クリエイティブの各カテゴリでも使えます。画面幅が狭い場合は「◇」と表示し、説明をツールチップに表示します。Curiosの既存ボタンの処理を使うため、持ち上げ中のアイテムも元の処理に従って引き継ぎます。Curiosのボタンを設定で無効にしている場合は追加しません。

Mod入りの開発起動ではCuriosと武器Modの `accesstransformer.cfg` も適用します。プレイヤーのインベントリ描画時にCuriosが非公開フィールドへアクセスして失敗する問題を修正しました。隔離した実ゲームで、サバイバルとクリエイティブの通常カテゴリから、プレイヤー本人のボタンをマウスクリックしてCurios画面が開くことを確認済みです。

### MWA武器のBOT攻撃

MAWの盾使用中のチャージと発動目安、MAWの状態テキストをスマホに表示します。MAWが魂の炎として記録した炎上は青く表示し、通常の炎と区別します。消火・チャージ解除・切断で表示を消します。MAWなしでの起動も維持します。これらの追加UIはビルドと自動テストで検証しており、実ゲームでの表示確認は未実施です。

BOTの攻撃対象にプレイヤーと他のBOTを含めます。プレイヤーへのダメージにはサーバーのPvP設定・チームの同士討ち設定・対象のゲームモードが適用されます。自分のBOTは、自分の代理プレイヤーの範囲攻撃では傷つきません。

指定の武器Mod（MWA / `the_four_primitives_and_weapons`）を導入すると、スマホに「技 / 溜め」「抜刀 / 納刀」を表示します。「技 / 溜め」は短押しで通常技、1秒以上の長押しで溜め技を発動し、3秒で最大チャージになります。チャージ時間はBOT側のサーバー時刻で判定します。敵・プレイヤーを直接タップした場合も、対象武器ではMWAの通常技を使います。技の種類はMWAの武器NBTとBOT自身の技データに従います。PCプレイヤーの技設定はコピーしません。持ち物画面の「MAW 技の選択」から、現在のメインハンド武器・弓に許可された技をスロット別に設定できます。設定はその武器のNBTに保存し、他の参加者やPCプレイヤーには反映しません。手持ちが変わった場合は古い選択を拒否します。元のホイールの描画、武器タイプ全体への設定、ポーチ専用画面はまだ再現していません。

BOTの代理プレイヤーにも武器の攻撃力・攻撃速度を反映し、ModのPlayerTickイベントでコンボやクールダウンを更新します。技ボタンの操作は一時停止・切断で取り消します。サバイバルの実プレイヤーを対象に、通常のBOT攻撃と計都星の刀のMWA通常技が命中することを隔離ワールドで検証済みです。

MWAの武器では通常の攻撃ボタン（左クリック相当）もMWAの技として処理します。敵に直接照準が合っていなくても、空振りやブロックに向けて斜め斬りを発動できます。1撃目・2撃目・3撃目はModのコンボ設定に従います。押したまま1秒以上経過して離すと溜め技を使います。視点操作への切り替え・中断時は溜めを取り消します。隔離ワールドで、空中の1撃目 `upper_left_slash` とブロックに向けた2撃目 `upper_right_slash` の実行を確認済みです。

アクセサリーの空き枠と種類アイコンは、Curiosのスロット定義とMinecraftで読み込んだMOD・リソースパックの画像から描画してスマホへ送ります。MAWのMP表示は削除しています。

作業台・チェスト・かまどなどは、どのタッチ操作モードでも映像内のブロックを短くタップすると開きます。専用の「機能ブロックを開く」ボタンは不要です。スワイプは視点操作、タップ操作モードの長押しは破壊です。スニーク中は通常の設置・使用動作を優先します。

標準チェスト・作業台・かまどなどのGUIは、参加者のメニュー内容を独立した描画用インベントリへコピーし、Minecraftの登録画面の背景・文字・アイテム描画からPNGを生成します。PC本人の画面や持ち物は切り替えません。画像のメニューIDと更新番号が一致する場合のみ、透明な操作枠に重ねます。体力・防御力・満腹度は、読み込み中のリソースパックの `minecraft:textures/gui/icons.png` を参照します。

現在のGUI画像対応は標準メニューの一部です。持ち物・アクセサリー全体やMOD独自画面、取引・ビーコン・エンチャントなど追加のクライアント状態が必要な画面は既存表示へ戻します。MOD独自オーバーレイの自動取得は未対応です。実ゲームでの描画確認は未実施です。

炎・魂の炎・凍結の画面効果にもMinecraftの読み込み中のリソースを使用します。炎は取得時のアトラス画像を用いた表示で、元の連続アニメーションの再生までは同期しません。

公開中継の主催者接続はhrmcngs用としてRenderに登録したMacの署名キーに限定します。公開鍵登録とデプロイの手順は [主催者登録](relay/OWNER_SETUP.md) を参照してください。招待したスマホは従来どおり参加できます。

## オフラインでローカルスキンPNGを使う

PC本人は **F8 → スキンPNG** でPNGを選択（またはファイルパスを入力）し、通常腕・細い腕を選んで「適用・保存」。外部スキンサービスには接続しません。PC内のプレイヤー表示と一人称の腕に適用するローカル設定で、Microsoftアカウントのスキン登録を変更するものではありません。

BOTはスマホの **設定 → スキンPNG → PNGをBOTに適用**。64×64・64KB以内のPNGに対応し、通常腕・細い腕を選べます。端末内にも保存し、次回の接続で再送します。既定スキンへ戻すときは種類を選び「名前とスキンを変更」。PNGはホストPCの `config/craftlink/skins/` に保存し、PC本人の選択も次回起動へ引き継ぎます（最大64スキン）。

インターネットは不要です。BOTへの送信にはスマホとPCのLAN接続または対応するUSB接続が必要です。ローカルスキンは外部Minecraftサーバーの他プレイヤーへ配布・同期するものではありません。実ゲームでの描画確認は未実施です。
