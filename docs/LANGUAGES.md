# 言語設定

- MOD画面: Minecraftの「設定 → 言語」に連動します。日本語・英語を用意しています。
- スマホの操作画面・BOT画面: 設定内の「Language / 言語」で日本語・Englishを選べます。初回はブラウザの言語を使い、日本語以外は英語になります。
- スマホの選択はブラウザに保存されます。保存が禁止されていても、その画面内では切り替えできます。

## 翻訳の追加

Minecraft: `src/main/resources/assets/craftlink/lang/ja_jp.json` と `en_us.json`。画面の固定ラベルは翻訳キーで参照します。

Web: `web/src/i18n/en.json` は日本語の表示文に対応する英訳です。`index.ts` が画面生成後や状態更新時にも反映します。操作パケットの値は翻訳しません。

現時点では日本語・英語の主要画面に対応しています。一部の詳細エラー・説明文には日本語が残ります。アイテム名やMOD固有の名称、ゲーム映像内の文字はPC側Minecraftから届く表示を使います。起動用シェルメニューの説明は日本語です。
