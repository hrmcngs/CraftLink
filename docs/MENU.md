# 対話式メニュー

リポジトリのフォルダーで実行します。

```sh
sh menu.sh
```

番号を入力してEnterで決定します。起動したMinecraftや中継を終了するとメニューへ戻ります。`0` で終了、Ctrl+Cで中断します。

| 番号 | 操作 |
| --- | --- |
| 1 | CraftLinkをビルド |
| 2 | 通常起動（LAN / Wi-Fi） |
| 3 | Android USB起動 |
| 4 | 依存取得・起動準備だけ実行 |
| 5 | 依存のダウンロードを許可／取得済みキャッシュだけに切り替え |
| 6 | LAN / USB起動ポートを指定 |
| 7 | 接続方法の説明 |
| 8 | CloudflareのHTTPS中継を単独起動 |
| 9 | 公開済みHTTPS中継へ単独接続 |
| 10 | 学校用まとめて起動（BOT参加） |
| 11 | dev・Microsoftログイン・保存済み本人情報・前回の状態から選択 |
| 12 | 学校用まとめて起動（自分のプレイヤーを操作） |
| 13 | 学校用の中継認証キーを再設定して起動 |
| 14 | 追加MODあり／なしを切り替え |
| 15 | 追加MODセットだけをビルド |
| 0 | メニューを終了 |

## よく使う流れ

- **学校用BOT**：必要なら11でログイン状態を選び、10で起動。
- **追加MODも使用**：14で有効にしてから2・3・10・12などで起動。
- **初回準備**：5で依存取得をonlineにし、4で準備。Microsoft本人情報の保存には実際にタイトル画面まで起動する必要があります。
- **依存取得済みの学校用起動**：5でofflineにして10で起動。これは依存取得の設定で、中継通信はインターネット接続が必要です。

ログインの選択は実行先の起動スクリプトが通常用・学校用に分けて保持します。11の「保存した起動状態を復元」で次回も使えます。Microsoft認証情報も再利用しますが、期限切れ・失効時は再認証が必要です。

依存取得・ポート・追加MODの切り替えはメニュー実行中の設定です。ポート指定は2・3・4に適用し、学校用は既存のMinecraft設定を使います。追加MODには別のMODプロジェクトなどの準備が必要です。8・9は別ターミナルでMinecraftと併用するための操作で、まとめて起動する場合は10・12を使います。

学校用中継の主催者認証・登録を省略する機能ではありません。[主催者登録](../relay/OWNER_SETUP.md)・[詳細ガイド](USER_GUIDE.md)も参照してください。
