# 対話式メニュー

リポジトリのフォルダーで実行します。

```sh
sh craftlink
```

VS Codeは **⌘ShiftB** からも開けます。

**起動するには「1」またはEnterを押すだけです。** 最初は学校用BOT起動を選択しています。

| 最初の画面 | 操作 |
| --- | --- |
| 1 / Enter | Minecraftを起動 |
| 2 | 起動方法を変更：学校用BOT・同じWi-Fi・Android USB・学校用プレイヤー |
| 3 | ログイン・追加MOD・依存ダウンロード・LAN/USBポート・中継認証設定 |
| 4 | 詳細メニューへ進む |
| 5 | 簡単な使い方を表示 |
| 0 | 終了 |

起動方法・設定を選んだ後は最初の画面へ戻ります。1を押すと設定に従って起動します。起動したMinecraftを終了するとメニューへ戻ります。Ctrl+Cで中断します。

## 詳細メニュー

最初の画面の **4** から開きます。以下の番号は詳細メニュー内の番号です。0で最初の画面へ戻ります。

| 番号 | 操作 |
| --- | --- |
| 1 | CraftLinkをビルド |
| 2 | 通常起動（LAN / Wi-Fi） |
| 3 | Android USB起動 |
| 4 | 依存取得・起動準備だけ実行 |
| 5 | 依存のダウンロードを許可／取得済みキャッシュだけに切り替え |
| 6 | LAN / USB起動ポートを指定 |
| 7 | 接続方法の説明 |
| 8 | CloudflareのHTTPS中継を単独起動 |
| 9 | 公開済みHTTPS中継へ単独接続 |
| 10 | 学校用まとめて起動（BOT参加） |
| 11 | dev・Microsoftログイン・保存済み本人情報・前回の状態から選択 |
| 12 | 学校用まとめて起動（自分のプレイヤーを操作） |
| 13 | 学校用の中継認証キーを再設定して起動 |
| 14 | 追加MODあり／なしを切り替え |
| 15 | 追加MODセットだけをビルド |
| 16 / ? | 各コマンドの目的・実行先・使い方を表示 |
| 0 | 最初の画面へ戻る |

## よく使う流れ

- **学校用BOTを起動**：最初の画面で1またはEnter。
- **同じWi-Fiで起動**：2 → 2で方法を選び、最初の画面の1で起動。
- **ログイン変更**：3 → 1から状態を選び、最初の画面の1で起動。
- **追加MODも使用**：3 → 2で有効にしてから、最初の画面の1で起動。
- **初回準備だけ行う**：4で詳細メニューへ進み、その中の4を選択。本人情報の保存には実際にタイトル画面まで起動する必要があります。

ログインの選択・認証情報は既存の保存機能を使用します。期限切れ・失効時は再認証が必要です。

依存取得・ポート・追加MODの切り替えはメニュー実行中の設定です。ポート指定は2・3・4に適用し、学校用は既存のMinecraft設定を使います。追加MODには別のMODプロジェクトなどの準備が必要です。8・9は別ターミナルでMinecraftと併用するための操作で、まとめて起動する場合は10・12を使います。

学校用中継の主催者認証・登録を省略する機能ではありません。[主催者登録](../relay/OWNER_SETUP.md)・[詳細ガイド](USER_GUIDE.md)も参照してください。

## コマンドの説明とzsh拡張

普段の入口は `craftlink` です。

```sh
sh craftlink help school  # 学校用起動が何を実行するか確認
sh craftlink help login   # 認証・保存先・各ログイン状態の説明
sh craftlink help terminal
```

現在のzshに短縮コマンドとTab補完を追加する場合、プロジェクト内で実行します。

```zsh
source scripts/terminal.zsh
craftlink             # 以後は sh やファイルの場所を省略できる
craftlink help school
```

別のフォルダーへ移動した後も使えます。`craftlink ` の後にTabで操作候補、`craftlink school ` の後にTabでオプション候補を表示します。現在のターミナルへ追加する方式で、グローバルインストールや `.zshrc` の自動変更は行いません。新しいターミナルでは再度sourceしてください。

既存の `run.sh` などは既存タスク・起動手順との互換用です。`scripts/` は内部処理の実装、`craftlink` は利用者が操作を選ぶ共通入口です。

## 中継がHTTP 403で接続を拒否する場合

自動再接続を停止してメニューへ戻ります。**3 → 5**で公開鍵を表示し、Renderの登録値と照合してください。**3 → 6**で保存済みの中継キーを再設定できます。[詳しい確認手順](../relay/OWNER_SETUP.md#http-403で起動できない場合)を参照してください。Minecraftのログイン設定とは別です。
