# 自分のPCでMODを入れて部屋を作る

## 必要なもの

- Minecraft Java Edition 1.20.1と、そのPCで使えるMinecraftアカウント
- Forge 47.4.10以降の47系とJava 17
- `mods/craftlink-forge-1.20.1-0.1.0.jar`（このZIPに同梱）
- 参加するスマホのブラウザ。スマホにMinecraftやJava、MODを入れる必要はありません。

配布ZIPを使う人には、ソースコード・Node.js・Gradleは不要です。

## インストール

1. ランチャーでMinecraft 1.20.1 / Forgeのインスタンスを用意します。
2. そのインスタンスのゲームフォルダーを開きます。MODパックの場合はランチャーの「フォルダーを開く」を使ってください。
3. ZIP内の `mods` にあるCraftLinkのJARを、ゲームフォルダーの `mods` へコピーします。同じCraftLinkの古いJARがあれば入れ替えて、二重に置かないでください。
4. 遊びたいMODと、そのMODが必要とする依存MODを同じ `mods` に配置します。Minecraft 1.20.1 / Forge用を選び、Fabric版や別バージョンと混在させないでください。
5. Forgeのインスタンスを起動します。MOD一覧にCraftLinkが出ることを確認します。

CraftLinkはCurios、特定の武器MOD、バックパックMODを必須にしません。このZIPにも他作者のMODやMinecraft本体は同梱しません。

## スマホから参加する部屋を作る

1. PCとスマホを直接通信できる同じWi-Fi/LANにつなぎます。
2. PCでシングルプレイのワールドを開きます。
3. **F8 → みんなで参加 → 受付を開始**を選びます。MacではFn + F8が必要な場合があります。キーが他のMODと重なる場合はMinecraftのキー設定で変更してください。
4. スマホで表示されたQRコードを読み取ります。
5. PC側で参加要求を承認し、「開始 / 再開」を選ぶと、そのスマホのBOTで遊べます。別のスマホも同じQRから参加できます。
6. 終了するときはPC側の「部屋を終了」を選びます。

初回のファイアウォール確認では、利用しているLANでの通信を許可します。スマホからページが開かない場合は、Wi-Fiの端末間通信制限・PCのファイアウォール・接続先のネットワークを確認してください。

別のWi-Fiやモバイル回線からの参加は、このLAN手順とは別にHTTPS中継の設定が必要です。MODを追加・更新するときはMinecraftを終了し、再起動して部屋を作り直してください。

## MODの対応範囲

- ブロックやアイテム、クリエイティブタブは、ホストPCに導入したMODから取得します。スマホはPC上のBOTを操作します。
- 標準的な収納メニューはスマホ側のスロット表示に連携します。MOD独自のボタンや設定画面には個別対応が必要です。
- Curiosがある場合はアクセサリー枠と登録済み3D描画を連携します。
- Sophisticated Backpacksがある場合はインベントリに「バックパックを開く」が表示され、所持品とCurios装備からバッグを検索します。専用アップグレード設定画面には未対応です。
- Player専用の効果・独自キー操作・シェーダー・特殊なGUIなど、すべてのMODの動作を保証するものではありません。上記の追加連携はビルド検証済みですが、各MODを導入した環境での実動作確認は別途必要です。

各PCは独立したホストとして別の部屋を作れます。PC同士で同じMinecraftワールドに入る場合は、参加先のルールに従ってMOD構成を揃えてください。複数BOTの部屋はシングルプレイ/LANのホストで使用し、通常のマルチプレイサーバーでは自分のプレイヤーの操作になります。

## 配布物をビルドする人向け

JDK 17・Node.js 22・npmを用意し、プロジェクトで `sh build.sh` を実行します。Windowsでは `gradlew.bat build` を使えます。依存取得済みなら `sh build.sh offline`、または `gradlew.bat build --offline -PwebOffline=true` です。

出力は `build/distributions/craftlink-host-forge-1.20.1-0.1.0.zip`。このZIPを各PCの利用者に渡してください。配布されるJARにはWeb UIと必要な組み込みライブラリが含まれ、開発者個人のMODプロジェクトへのパスは必要ありません。
