## CraftLink 0.1.0 — Initial beta

- Browser-based phone and tablet touch controller with in-game QR connections.
- Local-network controller mode and multi-device bot rooms.
- Live bot-view streaming, touch targeting, inventory controls, and creative item tabs.
- Custom touch layouts, nicknames, built-in skins, and local skin PNG support.
- Pause and disconnect handling that releases held controls.

For Minecraft Java Edition 1.20.1, Forge 47.4.10+ in the 47.x series, and Java 17. This public build supports local-network and configured Android USB connections. Public internet relays are not included.

This is an initial beta. Graphics, mobile-browser behavior, performance with many participants, and third-party mod compatibility still need broader testing.
