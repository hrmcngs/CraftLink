# 32×32アイコンの作り方

現在のアイコンは、32×32の整数座標と固定パレットを直接指定して描いています。以前の生成画像や縮小処理は使用していません。

- スマホ：平行な側面・直線の画面枠・中央の十字キー。
- ブロック：左右対称の上面と、高さが等しい左右の面。
- 接続：角を揃えた緑のリンク。
- 原画：`icon-32.png`（32×32）。
- アップロード用：`icon.png`（512×512）。原画の各ピクセルを16×16でそのまま複製しています。

元データは [`scripts/PixelIcon.java`](../../scripts/PixelIcon.java) です。JDK 17だけで再生成できます。外部画像・Python・画像生成サービスは使いません。

```sh
java scripts/PixelIcon.java
```

形や配色を変更したら、通常のビルドでMOD一覧用画像と配布JARへ反映できます。
